# Vibe Marketing B2B Skill v2.1.0

v2.1.0 turns the established text-panel visual baseline into an enforceable production gate.

## Highlights

- `production-contract.json` now defines one shared text-panel system.
- The default panel fill is exactly `rgba(255,255,255,0.30)`.
- Apple-like corner radius must remain within `24-36 px`.
- Horizontal text-to-panel padding must be at least `48 px` on a `1080 x 1920` canvas.
- Every declared audience-facing text-panel selector must bind the contract background, radius, and padding variables.
- Hard-coded near-opaque backgrounds, square panels, and cramped padding stop the render before media generation.

## Verified failure cases

The regression suite now confirms that each of these defects blocks delivery:

- a panel alpha changed from `0.30` to `0.95`;
- a corner radius changed to `0`;
- horizontal padding reduced below `48 px`;
- an audience-facing selector that omits a shared panel token.

## Upgrade notes

Add `visualRules.textPanels` to an existing v2.0.0 contract, export `--text-panel-bg`, `--text-panel-radius`, and `--text-panel-padding-x` from the contract adapter, and list all panel selectors for preflight inspection.
