# Vibe Marketing B2B Skill v2.0.0

v2.0.0 turns the video-production rules into an enforceable Remotion delivery system. It is a breaking workflow upgrade for final rendered videos; strategy and copy-only usage is unchanged.

## Highlights

- One approved `production-contract.json` controls canvas, text, typography, timing, media, visible-speaker status, and render settings.
- A checksum lock prevents approved values from drifting silently during implementation.
- Real-font Chrome line-box inspection blocks overflow, excessive lines, punctuation at line start, and orphan final lines.
- The default vertical-video baseline is enforced: title 120 px, body/subtitle 60 px, note/remark 35 px.
- Narrated videos use a 0.40-second sentence-ending pause for `。？！` by default, with ±0.03-second tolerance.
- Visible-mouth shots require both exact audio authority and normal-speed human lip-sync approval.
- The final render command must run preflight first. A separate post-render audit checks stream starts, decode, loudness, true peak, and isolated flashes.
- A bundled workspace initializer gives every project the same local structure without overwriting existing files.

## Verified failure cases

The regression suite confirms that each of these defects blocks delivery:

- body text drifting from 60 px to 52 px;
- an orphan one-character final line;
- a sentence-ending pause shortened from 0.40 seconds to 0.08 seconds;
- a narration checksum mismatch.

## Upgrade notes

Existing Remotion projects must add and lock a production contract, import contract values into the composition, route `npm run render` through preflight, and run the post-render audit before delivery. See [`vibe-marketing-b2b/references/remotion-production-contract.md`](../vibe-marketing-b2b/references/remotion-production-contract.md).
