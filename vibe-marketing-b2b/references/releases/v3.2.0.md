# vibe-marketing-b2b v3.2.0

发布日期：2026-10-28

制作：Victor使用Codex制作

本次版本把“读对”扩展为“把核心信息读出来”。每个连续发言在气口设计和合成前，必须明确核心命题、表达意图、主重音、次重音、去重音信息及表达说明。重音短语必须完整存在于实际配音文本中，不能同时被标为主重音和次重音。

重音不通过任意增加标点、拆词、多次TTS请求或机械拉长停顿实现。正常速度的上下文试听必须确认主信息最突出、次信息只承担立题或补足作用；文字计划、标点和波形振幅不能代替听审。

示例显示文案为“上海的AI教师培养，开始给老师配一张‘学习路线图’”。Kokoro配音使用中文释义“人工智能”，Victor沿用既有`zm_yunyang`绑定；本版本没有更换声音、模型或渲染器。
