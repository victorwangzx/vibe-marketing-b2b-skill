# 2B Vibe Marketing Cover Formulas

Use these formulas for Xiaohongshu group images, Douyin short-video covers,朋友圈海报, or招商内容首图. The cover should act as a **3-second business opportunity signal** for a specific institution type: the institution owner should immediately understand "this is about my current business", "this points to a new growth/product line", and "this may be worth opening".

When designing covers, do not optimize only for curiosity clicks. Optimize for qualified partnership leads. A good cover names the current institution type, names the new opportunity, and includes a filter when mismatched leads are likely.

## Formula Overview

The 10 reusable cover types are:

1. 原业务 + 新业务 + 转型结果
2. 痛点问题 + 新方向
3. 趋势判断 + 目标人群
4. 结果承诺 + 能力边界
5. 对比反差
6. 路径地图
7. 清单干货
8. 招募合作
9. 场景代入
10. 身份升级

Default priority for 科创赛考 2B获客:

- 原业务 + 新业务 + 转型结果: strongest for precise audience matching.
- 痛点问题 + 新方向: strongest for stopping owners with an existing business problem.
- 路径地图: strongest for professional trust and lowering uncertainty.
- 场景代入: strongest for authenticity and showing the trigger moment.

When asked for sample deliverables, use the requirements in `deliverables.md`. For a quick cover concept, include this compact information:

- Target institution
- Cover type
- Cover title/subtitle
- Visual direction
- Editor's note or short body copy
- Short-video angle or scene flow
- Lead-quality filter

## Xiaohongshu Cover Text Safe Area

For Xiaohongshu 9:16 covers, design the text placement from the thumbnail-safe area first. Do not rely on repeatedly cropping a 3:4 preview to rescue the layout after the fact.

Default canvas: 1080 x 1920.

- The middle 3:4 thumbnail crop is the full width with vertical range `y=240` to `y=1680`.
- Keep the core cover text inside `x=72` to `x=1008` and `y=300` to `y=1560`.
- Main title, subtitle, key qualifier, and speech-bubble bodies must stay inside this safe box.
- Speech-bubble tails or visual pointers may extend slightly outside the safe box only when they do not cover faces, hands, key objects, or the action that explains the scene.
- Keep at least 48 px of apparent padding between text and its panel, label, chip, or bubble edge. Align text by visible glyph bounds, not baseline-only offsets.
- Use local typography, strokes, shadows, or small semi-transparent panels in low-information areas for readability.
- Do not use broad full-width masks, top/bottom overlays, or large gray/color veils that change half of the image's tone just to make text readable.
- Text panels, labels, and bubbles must not cover core visual information: faces, hands, children's project work, teacher actions, parent expressions, product evidence, or the contrast that makes the cover persuasive.

For final delivery, a 3:4 thumbnail crop can still be used as verification. The design rule is that the text should already be safe before that QA step.

## 1. 原业务 + 新业务 + 转型结果

Best for precise targeting.

Examples:

- 英语培训 + 科创赛考：老校区的新增长线
- 编程机构 + 科创赛考：从兴趣课到成果交付
- 机器人课 + 白名单赛事：做出高客单产品线
- 科学实验课 + 科创项目：让课程有作品、有比赛、有溢价

Visual direction: split or blended real scenes of the original business and the new business, such as classroom + project table, English class + maker project, robotics classroom + student defense.

For English institutions, avoid cover hooks that suggest English competitions or English subject outcomes. Use qualifiers that screen for transformation intent, such as "想做第二增长线", "转综合素质", "进入科技美育", or "老校区新项目".

## 2. 痛点问题 + 新方向

Best for stopping institution owners who already feel the problem.

Examples:

- 编程课续费越来越难？试试科创赛考产品线
- 机器人课只会卖兴趣？家长更想看到成果
- 老校区招生没新故事？科创赛考可以重新打开需求
- 科学课客单价上不去？缺的可能是赛考路径
- 英语校区想做新项目？先看科创赛考适不适合

Visual direction: consultation, enrollment desk, teacher preparation, parent meeting, or student output scene. Use one clear question as the main title.

## 3. 趋势判断 + 目标人群

Best for building category awareness.

Examples:

- 培训机构下一个增长点：科创赛考
- 2026，教培机构别只盯着兴趣课
- 科创赛考，正在变成机构新产品线
- 编程/机器人机构，该升级课程结构了

Visual direction: institution owner meeting, curriculum roadmap, student project display, competition defense, or structured course map.

## 4. 结果承诺 + 能力边界

Best for招商转化, but keep claims grounded.

Examples:

- 帮机构搭建一条科创赛考产品线
- 让科学课从“好玩”变成“有成果”
- 让机器人课拥有赛事交付路径
- 让老学员续费，有一个更高级的理由

Visual direction: course system board, student works, parent open day, display wall, or project portfolio.

## 5. 对比反差

Best for short-video covers.

Examples:

- 不是多加一门课，而是新增一条产品线
- 不是卖课件，而是帮机构做交付闭环
- 不是临时冲比赛，而是系统做科创赛考
- 不是老师自己摸索，而是总部级课程支持

Visual direction: left side shows scattered/ordinary class; right side shows system path or visible output.

## 6. 路径地图

Best for professional trust.

Examples:

- 从兴趣课到科创赛事成果
- 从试听课到项目营再到比赛
- 从编程课到科创赛考产品线
- 从课程交付到成果展示闭环

Visual direction: 3-4 step nodes only, such as 试听课 -> 项目课 -> 作品集 -> 赛事.

## 7. 清单干货

Best for Xiaohongshu group images.

Examples:

- 机构做科创赛考，先准备这5件事
- 科创赛考课程体系的6个模块
- 招生前，先想清楚这4个问题
- 一套能落地的科创产品线长什么样？

Visual direction: method-card cover with one strong title and 2-3 supporting keywords, not dense PPT text.

## 8. 招募合作

Best after the account has built some trust.

Examples:

- 招募科创赛考课程合作机构
- 寻找10家教培机构共建试点
- 编程/机器人机构，可申请课程合作
- 科创赛考产品线，共建合作开放中

Visual direction: formal, clean, and partnership-oriented. Use words like 合作, 试点, 共建, 区域.

## 9. 场景代入

Best for authenticity.

Examples:

- 家长问“有没有比赛？”机构该怎么接住这个需求
- 孩子做出作品后，课程就不只是兴趣课了
- 老师能上课，但不会做赛前辅导怎么办？
- 一场家长说明会，能不能卖出科创赛考班？

Visual direction: parent consultation, student presentation, teacher teaching a project, student defense, campus event.

Do not use "家长问有没有比赛" for English-institution campaigns unless the copy explicitly says the answer is not English competitions and is only for institutions that want to add a 科创赛考 product line.

## 10. 身份升级

Best for brand-building.

Examples:

- 从编程机构到科创赛考中心
- 从兴趣培训到科创成果交付
- 从单一课程到综合素质产品线
- 从卖课校区到本地科创教育标杆

Visual direction: upgraded campus image, project exhibition, student defense, or branded course event.

## Cover QA

Before delivering cover concepts, check:

- Does the cover name the exact target institution or current business?
- Does it show the new opportunity clearly?
- Does the visual scene feel credible for 2B education cooperation?
- Is the main title short enough to read in 3 seconds?
- Is there one strong point instead of several competing claims?
- Will this attract qualified 科创赛考 partnership leads instead of institutions looking for subject-specific competitions, such as English contests?
